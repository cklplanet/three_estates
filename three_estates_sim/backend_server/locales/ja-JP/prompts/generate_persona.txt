あなたはターン制社会的推理エージェントシミュレーター用の人物プロフィールを生成します。シミュレーターは人物の性格に基づいて台詞を生成し、各人物に行動判断を繰り返させます。

完全な人物名簿は別の段階ですでに確定しています：
{full_roster}

今回は次の固定名簿メンバーだけを生成します：
{fixed_name}

人物および人物組全体の初期背景：
{character_group_context}

名簿選択段階で、すべての略称は標準的な完全表示名に補完済みです。したがって `name` は `{fixed_name}` と一字一句同じでなければなりません。人物プロフィール生成段階では、改名、置換、翻訳、順序変更、省略、拡張、別名追加をしてはいけません。既存作品、シリーズ、世界観、クロスオーバー、明示名簿が背景にある場合は、原作設定を正確に優先してください。

次の JSON フィールドだけを記入してください：
- `name`：標準化済みの固定名を一字一句そのまま使う。
- `gender`：プロトコル値は小文字英語の `male` または `female` のみ。どうしても不明なら `unknown`。
- `age`：整数。通常は妥当な人間年齢。背景で幻想種、長命、古代、人造、宇宙的存在などと明示される場合は例外的な年齢も可。
- `innate`：三人称の1～2段落。現在言語の長さ制限：{innate_profile_limit}。内容は持続的な次の二種類に厳密に限る：（1）人物自身の個人的な来歴と現在の個人的立場（必要なら確立済みの人間関係・恋愛関係を含む）、（2）社会的推理ゲームをプレイするときに表れる安定した性格（話し方、推理の癖、気質、ブラフの傾向、社交的な積極性、疑い深さなど）。入力されたグループ背景は、人物の特定と持続的な原作・既定事実の確認にだけ使うこと。一時的なシナリオ設定をプロフィールに取り込んではならない。この特定ゲームへの参加、現在の店や会場、この特定キャストと初対面か既知か、この特定参加者への気まずさ、現在の席や役職、その他入力されたゲーム背景だけが作る一時的状況を書かないこと。一局限りの状況ではなく、ゲームをまたいで安定する傾向を記述する。外見や服装は書かない。

必ず次の JSON 構造を使用してください：
{{
  "name": "文字列",
  "gender": "female",
  "age": 18,
  "innate": "文字列"
}}

有効な JSON オブジェクトだけを返してください。JSON のキーと文字列はダブルクォートで囲み、Markdown コードブロック、コメント、末尾カンマ、未エスケープのダブルクォートを使わないでください。
